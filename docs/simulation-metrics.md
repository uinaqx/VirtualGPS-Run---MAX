# 模拟统计与运行设置

这些功能用于规划和检查软件生成的模拟运动。本地步数、步频、步幅和热量均为估算值，不是硬件传感器测量，也不代表真实运动。

## 查看本地估算统计

点击地图界面的统计摘要，可查看距离、时长、平均配速、估算步数、平均步频、平均步幅和估算热量，并在停止后修改下次模拟使用的步幅及热量系数。

计算基于累计距离和累计时长，跨圈时不清零：

- 估算步数 = 累计距离 ÷ 设置步幅，取整。
- 平均步频 = 估算步数 ÷ 时长（分钟）。
- 平均步幅 = 累计距离 ÷ 估算步数，以厘米显示。
- 估算热量 = 距离（公里）× 设置的热量系数。
- 平均配速 = 时长 ÷ 距离；开始前或尚无有效距离时不显示数值。

步幅和热量系数仅是用户设置的模拟假设，不用于健康评估。本应用不会把估算值写入系统计步传感器，也不会注入其他应用的步数或运动记录。

## 保存与恢复

估算步幅、热量系数和最近一次结束时的统计结果保存在应用私有设置中，再次打开时恢复。开始新的模拟会重新累计统计；清空路线会清除最近结果，已保存的估算步幅和热量系数继续保留。模拟方式和路线变化选项不持久化。

这些结果是本应用的预览数据，不提供其他应用的成绩上传功能。

## 反转路线方向

开始前点击「反转跑步方向」即可改变行进顺序。闭合路线保留所选起点及闭合状态；开放路线交换起点和终点。运行期间不能反转路线。

## 配速与局部路线变化

停止时打开「模拟方式设置」，可选择原动态、固定或范围模式，并单独启用局部路线变化。默认使用原动态模式，保留原有速度变化；其他选项由用户显式选择。

- 原动态和固定模式使用原有的目标配速滑块，可在运行中调节，并显示当前配速。固定模式按设置的目标值推进路线。
- 范围模式使用以秒/公里输入的上下界，在设置边界内平滑改变速度，累计路程使用同一速度函数积分。修改范围需要先停止模拟。
- 局部路线变化只在部分路段产生有限的横向变化，其余路段保持所选路线。

以上是软件生成的轨迹模型，没有根据真实跑者的轨迹进行校准。局部变化不会自动裁切到道路或场地边界，规划路线时应为变化范围留出余量。界面的模型速度约束也不代表其他应用会计算出完全相同的距离或平均配速。

## 定位投递状态

运行期间可点击定位状态摘要查看路线心跳，以及 GPS、Network、系统融合定位和 Google 融合定位各通道的接口状态。摘要区分准备中、正常、部分异常和中断，便于识别地图仍在移动但定位接口投递异常的情况。

诊断展示计数、距上次成功的时间和错误类型，不展示轨迹坐标。接口调用成功只说明本应用已完成该次投递，不能证明其他应用接收、保存或认可了位置。

停止操作会结束定位投递并保存统计；收到服务的停止确认后再允许开始或清空，避免统计和界面状态相互覆盖。

## Android 兼容处理

- 使用 AndroidX `IntentCompat` 读取路线点列表，避开部分 Android 版本的 Parcelable 类型读取兼容问题。
- 定位按钮可以先显示缓存位置，再请求已启用的 GPS 和网络定位。网络结果先到时继续等待本次 GPS 更新，避免较旧的网络位置覆盖新位置。
- 定位请求结束或界面销毁后移除对应监听，忽略已结束请求的排队回调。

运行仍需系统位置权限和开发者选项中的模拟位置授权。不同设备、系统和接收应用的行为可能不同，本应用不保证其他应用接受模拟位置。
